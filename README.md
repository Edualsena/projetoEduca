## Privacidade (resumo)
A plataforma coleta apenas dados necessários para o uso:
- Nome, e-mail e senha (senha armazenada com hash)
- Resultados de quizzes para histórico e ranking
Os dados ficam no banco local da aplicação. Não há venda ou compartilhamento externo de informações da comunidade.
